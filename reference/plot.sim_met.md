# Diagnostic Plot for a Simulated MET

Scatter of the target against the realised (K-whitened) off-diagonal
environment correlations, with the 1:1 line.

## Usage

``` r
# S3 method for class 'sim_met'
plot(x, ...)
```

## Arguments

- x:

  a `sim_met` object.

- ...:

  passed to [`plot`](https://rdrr.io/r/graphics/plot.default.html).

## Value

`x`, invisibly.
