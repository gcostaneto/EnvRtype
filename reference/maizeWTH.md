# Maize Weather Data

Weather data collected from NASA POWER for each one of the five
environments in HELIX dataset.

## Usage

``` r
data(maizeWTH)
```

## Format

A data.frame containing weather variables for each environment in HEL
dataset

## Examples

``` r
if (FALSE) { # \dontrun{
data(maizeWTH); head(maizeWTH)
} # }
```
